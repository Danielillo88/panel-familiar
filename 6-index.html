Marco de fotos

Las fotos se eligen desde tu fototeca, se comprimen y se guardan en este iPhone: no se suben ni se comparten con nadie. Si borras los datos de este sitio en Safari, habría que elegirlas otra vez.

Este navegador no permite guardar las fotos entre aperturas; se mantendrán mientras la página siga abierta.

Para que la pantalla no se apague mientras usas el marco, la app pedirá mantenerla despierta al abrirlo. Funciona mientras el marco esté abierto y al frente; si bloqueas el móvil o cambias de app, se apaga igual.
